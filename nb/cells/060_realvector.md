### 0.6 · A real vector out of that space

`fits/u_L16.pt` is a genuine element of $\mathbb{R}^{3584}$ produced by this project — the
direction that every intervention in it clamps along. What it *means* is chapter 5's business;
here we only establish that it is an ordinary vector in the space chapter 0.5 described.

(A full per-token state array for one run is ~76 GB and is not staged. Vectors like this one are
the largest real pieces of the state space that fit in a kit you can carry.)
